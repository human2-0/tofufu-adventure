# Documentation

- Keep `AGENT_MAP.md` a concise routing index. Only list actual paths or clearly mark planned ones.
- Keep always-loaded instructions short; rationale, design alternatives, protocol details and roadmaps belong in architecture docs.
- Record status and consequences for architectural decisions. Update existing decisions when superseded; avoid duplicate sources of truth.
- Cite primary upstream documentation for external behavior. Label project design choices separately from guarantees made by a library.
