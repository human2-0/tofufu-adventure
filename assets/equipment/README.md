# Tofufu equipment art

Imported from the user-provided `Tofufu_Equipment_Assets.zip` and `Tofufu_Standing_Pose_Sheets.zip`.

- `bright_leaf_set/` and `dark_leaf_set/` contain the original item PNGs and equipment sheets.
- `../characters/fufu/sets/` contains the supplied walking, standing and jump sheets, with descriptive filenames and set mappings recorded in `../characters/fufu/sets/SOURCE.md`.

A complete visible outfit requires the matching helmet, armor, legs and boots. Individual item art remains available in the shop and equipment UI.
