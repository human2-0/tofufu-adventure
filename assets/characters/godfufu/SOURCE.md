# Godfufu

`godfufu.png` is a generated transparent placeholder NPC sprite, created with the
built-in image generation tool on 2026-10-04. The existing village Grandpa Fufu
art was supplied as a style reference. Godfufu is an ivory cuboid tofu block with
a golden halo and lavender sash, rather than the player's bean-shaped body.
The original generated RGBA image is preserved without background processing.

Used by `game/world/biomes/clouds/godfufu.gd`; this resident currently has an idle
animation and proximity greeting, with no quest or reward implementation.
